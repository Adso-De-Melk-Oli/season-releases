# SEASON

Versions installables de l'app Android SEASON.
Télécharge le fichier .apk de la dernière version depuis ton téléphone.

## Agenda

`data/agenda.json` est reconstruit chaque nuit par GitHub Actions à partir de données ouvertes :
DATAtourisme (fêtes et manifestations, offices de tourisme) et calendrier scolaire de l'Éducation nationale (zone C).

## Recettes

`data/recipes.json` : recettes de saison de l'app SEASON (mois, régime, kcal par part, option sans sel).
Pour ajouter une recette, modifier `scripts/recipes_data.py` : le fichier est reconstruit automatiquement.
